SALES AND REVENUE ANALYSIS PROJECT

1. PROJECT OVERVIEW

This project focuses on analysing sales and revenue
data using the Superstore dataset.

The objective is to identify sales trends, understand
customer purchasing behaviour, analyse product
performance and evaluate profitability.

The project uses Oracle SQL XE 11g for data analysis
and Microsoft Power BI for interactive visualization.

2. DATASET INFORMATION

Dataset Name: Superstore
Total Records: 9,994
Total Columns: 21

3. TOOLS AND TECHNOLOGIES

- Oracle Database XE 11g
- Oracle SQL Developer Extension for VS Code
- Microsoft Excel
- Microsoft Power BI
- Visual Studio Code
